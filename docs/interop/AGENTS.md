# docs/interop

Owns: researched facts about third-party systems (A2A spec, Hermes, ACP, omp, Claude Code, NATS).
Provides: sourced facts RFCs cite. Not normative for A2A-Bus.
Uses: public documentation and source; omp:// docs for omp.

## Rules

- Every claim has a source URL; unconfirmed claims carry `[UNVERIFIED]`.
- Quote exact names (methods, fields, enum spellings, error codes).
- Record the date and version of each source; update, never silently overwrite, when a source changes.
- No design decisions here. Proposals belong in RFCs.
