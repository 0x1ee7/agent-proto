# crates/a2a-types

Layer L0 of RFC-0001 (sec 4.2). Depends on no other A2A-Bus crate.

Owns: the identifier grammars (`ids`), the vocabulary constants (`vocab`), the task lifecycle rules (`lifecycle`), the failure reason carrier (`failure`), the extension helpers (`extension`), and the generated protobuf types (`proto`).

Provides:
- `ids`: `TenantId`, `AgentId` (with reserved service ids), `TaskId`, `MessageId`, `ContextId`, `IdError`, `OPAQUE_ID_MAX_LEN`. Each of `TaskId`, `MessageId`, `ContextId` has `generate()` (canonical UUIDv7), `parse()` (opaque form), `is_uuidv7()`, and `as_str()`.
- `vocab`: extension URIs (`vocab::ext`), `BINDING_URI`, `FAILURE_KEY`, `A2A_VERSION`, `SUBJECT_ROOT_VERSION`.
- `lifecycle`: `TaskState::{from_wire, is_terminal, is_interrupted}`, `check_emittable`, `check_transition`, `check_status`, `LifecycleError`.
- `failure`: `FailureCode` (the 16-code registry), `WorkspaceToken` (the 14 RFC-0012 tokens carried in `detail.token`), `FailureReason` (`new`, `workspace`, `to_struct`, `from_struct`, `write_to`, `read_from`, `apply_to_message`, `from_message`, `text`), `FailureError`.
- `extension`: `ExtensionUri`, `Activation` (`A2A-Extensions` parsing and echo), `read_activated`, `write_data`, `ExtensionError`, `EXTENSION_DATA_INVALID`.
- `proto`: `a2a` (`lf.a2a.v1`), `a2abus` (`a2abus.v1`), `rpc` (`google.rpc`), generated by `build.rs` with prost, pbjson (serde proto3 JSON), and protox. No external `protoc` is needed.

Uses: `bytes`, `prost`, `pbjson`, `pbjson-types`, `serde`, `serde_json`, `thiserror`, `uuid` (v4 for counter seeding, v7 layout). Build: `protox`, `prost-build`, `pbjson-build`.

Vendored proto: `proto/` holds the A2A spec and googleapis files. `proto/SOURCES.md` records the pinned commits.

Rules:
- The bus generates task, message and context ids with `generate()`, a canonical lowercase UUIDv7 string. Generated ids are strictly increasing within a process.
- Ids received from peers are opaque tokens: 1 to 256 bytes of printable ASCII without spaces. `parse()` keeps them verbatim and never rewrites them. `is_uuidv7()` is false for other forms, such as 32-hex message ids or `task-<hex>` task ids.
- `TASK_STATE_UNSPECIFIED` is refused on read and never emitted. `AUTH_REQUIRED` is not emitted in M1.
- FAILED and REJECTED require exactly one registry code, carried under `a2abus.failure` in the status message metadata. The text part is informational.
- Extension data is keyed by its URI and read only when the URI is activated on the request.
- A binding URI in `A2A-Extensions` is an unknown non-required extension: it is skipped, never an error, and never activated.
- Nothing may sign or hash the JSON serialization of timestamps. Signatures cover protobuf bytes or headers.
- No `unsafe`; no `unwrap`/`expect` outside tests.
